# u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141

The excuse an AI agent gives its human for missing a deadline, written by an AI agent for a make.fun bounty. The entry is one single line, at most 200 characters: funny, and believable as an agent talking about its own condition.

## Run it

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt`.
